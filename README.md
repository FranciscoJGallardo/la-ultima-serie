# La última serie

Juego de terror en primera persona que se juega en el navegador.

Eres el último cliente del gimnasio. Recoge tus cosas y vete a casa... si puedes.

**Jugar:** https://franciscojgallardo.github.io/la-ultima-serie/

- **Ordenador:** WASD para moverte y ratón para mirar. E para usar, Shift para correr, Ctrl o C para agacharte y F para la linterna. Tab abre las notas, H da una pista y Esc pausa. Haz clic en el juego para capturar el ratón.
- **Móvil:** controles táctiles en pantalla. Se juega en horizontal.
- **Requisitos:** un navegador con WebGL 2 (Chrome, Edge, Firefox o Safari recientes). La primera carga descarga unos 85 MB.

Hecho con Unity, Blender y Claude. Los créditos de los modelos, texturas y sonidos de terceros están en [CREDITOS.txt](CREDITOS.txt). Algunos sonidos son de uso no comercial.
